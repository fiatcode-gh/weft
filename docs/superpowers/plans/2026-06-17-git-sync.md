# Git Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a top-level `s` keybind that runs commit → pull → push on the graph's git repo from inside weft, with async hint-only feedback and reindex-on-pull.

**Architecture:** A new `internal/sync/` package shells out to system `git` (no `go-git`) and returns a `Result` describing what happened. `internal/views/app.go` gains an injectable `syncRunner`, an `s` keybind in the page-view handler, and a `syncDoneMsg` handler that reports via the existing `setHint` mechanism, appends failure output to `weft.log`, and triggers a reindex when the pull changed the tree. The help overlay documents the key.

**Tech Stack:** Go 1.26+, `os/exec`, Bubble Tea (`charmbracelet/bubbletea`), teatest goldens (`charmbracelet/x/exp/teatest`).

## Global Constraints

- Module path: `git.fiatcode.dev/fiatcode/weft/v2`.
- Go 1.26+ (`go.mod`).
- `go vet ./... && go test ./...` must pass before every commit.
- Tests **never** point at the real graph (`~/Documents/fiat-codex`) and never hit the network. `internal/sync` tests build throwaway repos under `t.TempDir()` with a local bare remote.
- Sync operates on the `--graph` directory weft was launched with (`App.graphPath`), never a hardcoded path.
- View tests stub the sync runner; they never shell out to git.
- Commit messages: Conventional Commits (`feat:`, `test:`, `docs:`).

```go
func git(t *testing.T, dir string, args ...string) string {
	t.Helper()
	cmd := exec.Command("git", args...)
	cmd.Dir = dir
	// Deterministic identity + no global config bleed-through.
	cmd.Env = append([]string{
		"GIT_CONFIG_GLOBAL=/dev/null", "GIT_CONFIG_SYSTEM=/dev/null",
		"GIT_AUTHOR_NAME=t", "GIT_AUTHOR_EMAIL=t@t", "GIT_COMMITTER_NAME=t", "GIT_COMMITTER_EMAIL=t@t",
	}, "HOME=/dev/null")
	out, err := cmd.CombinedOutput()
	if err != nil {
		t.Fatalf("git %v: %v\n%s", args, err, out)
	}
	return string(out)
}

// newRepoWithRemote returns a work tree wired to a fresh bare origin,
// with one pushed commit on the default branch.
func newRepoWithRemote(t *testing.T) string {
	t.Helper()
	root := t.TempDir()
	origin := filepath.Join(root, "origin.git")
	work := filepath.Join(root, "work")
	git(t, root, "init", "--bare", "-b", "main", origin)
	git(t, root, "clone", origin, work)
	if err := os.WriteFile(filepath.Join(work, "seed.md"), []byte("seed\n"), 0o644); err != nil {
		t.Fatal(err)
	}
	git(t, work, "add", "-A")
	git(t, work, "commit", "-m", "seed")
	git(t, work, "push", "origin", "main")
	return work
}
```

```go
// Package sync performs weft's git synchronization: commit local changes,
// rebase-pull, then push. It is weft's second deliberate disk-mutating
// surface (alongside internal/edit) and shells out to the system `git`.
package sync

import (
	"fmt"
	"os/exec"
	"strings"
	"time"
)

// Result reports what a sync did and, on failure, where it stopped.
type Result struct {
	Committed bool   // a commit was created (working tree had changes)
	Pulled    bool   // pull --rebase advanced the working tree
	Pushed    bool   // push succeeded
	Stage     string // failing stage; "" on success
	Output    string // combined output of the failing stage; "" on success
	Err       error  // non-nil on failure
}

// Run performs commit -> pull --rebase -> push against repoDir. now is the
// commit-timestamp source, injected so callers (and tests) stay deterministic.
func Run(repoDir string, now time.Time) Result {
	run := func(args ...string) (string, error) {
		cmd := exec.Command("git", args...)
		cmd.Dir = repoDir
		out, err := cmd.CombinedOutput()
		return string(out), err
	}
	fail := func(stage, out string, err error) Result {
		return Result{Stage: stage, Output: out, Err: err}
	}

	// Preflight: must be inside a git work tree.
	if out, err := run("rev-parse", "--is-inside-work-tree"); err != nil {
		return fail("preflight", out, err)
	}

	var res Result

	// Commit local changes, if any.
	status, err := run("status", "--porcelain")
	if err != nil {
		return fail("add", status, err)
	}
	if strings.TrimSpace(status) != "" {
		if out, err := run("add", "-A"); err != nil {
			return fail("add", out, err)
		}
		msg := fmt.Sprintf("sync: %s", now.Format("2006-01-02 15:04"))
		if out, err := run("commit", "-m", msg); err != nil {
			return fail("commit", out, err)
		}
		res.Committed = true
	}

	// Pull --rebase; detect whether HEAD advanced.
	before, _ := run("rev-parse", "HEAD")
	if out, err := run("pull", "--rebase"); err != nil {
		return fail("pull", out, err)
	}
	after, _ := run("rev-parse", "HEAD")
	res.Pulled = strings.TrimSpace(before) != strings.TrimSpace(after)

	// Push.
	if out, err := run("push"); err != nil {
		res.Stage, res.Output, res.Err = "push", out, err
		return res
	}
	res.Pushed = true
	return res
}
```

```go
func TestSyncKeyShowsSyncingHintAndRunsRunner(t *testing.T) {
	a := bootApp(t)
	called := false
	a.syncFunc = func(repoDir string) syncpkg.Result {
		called = true
		return syncpkg.Result{Pushed: true}
	}
	model, cmd := a.Update(tea.KeyMsg{Type: tea.KeyRunes, Runes: []rune("s")})
	a = model.(*App)
```

```go
var errTest = errors.New("boom")

// drainFor runs cmd (and any tea.Batch children) until it produces a T.
func drainFor[T tea.Msg](t *testing.T, cmd tea.Cmd) T {
	t.Helper()
	var walk func(c tea.Cmd) (T, bool)
	walk = func(c tea.Cmd) (T, bool) {
		var zero T
		if c == nil {
			return zero, false
		}
		msg := c()
		if m, ok := msg.(T); ok {
			return m, true
		}
		if batch, ok := msg.(tea.BatchMsg); ok {
			for _, child := range batch {
				if m, ok := walk(child); ok {
					return m, true
				}
			}
		}
		return zero, false
	}
	m, ok := walk(cmd)
	if !ok {
		t.Fatalf("cmd did not produce %T", m)
	}
	return m
}
```

- [ ] **Step 5: Add the `logSyncFailure` helper**

Append to `app.go` (and add `"fmt"`, `"os"`, `"time"` to imports if not already present — `time` already is):

```go
// logSyncFailure appends a failing sync's captured git output to weft.log,
// the same path WEFT_DEBUG mirrors to — written here regardless of the flag
// so the hint's "see weft.log" pointer is always valid. Best-effort: a log
// write error is itself ignored (the hint already told the user it failed).
func (a *App) logSyncFailure(res syncpkg.Result) {
	f, err := os.OpenFile("weft.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0o644)
	if err != nil {
		return
	}
	defer f.Close()
	fmt.Fprintf(f, "sync %s failed at %s:\n%s\n", res.Stage, a.nowFunc().Format(time.RFC3339), res.Output)
}
```

## Notes for the implementer

- **No `cmd/weft` changes.** `App.graphPath` already carries the `--graph` directory; sync reuses it.
- **Fixture graph is not a git repo.** Running `s` against `testdata/fixture-graph` returns `Stage: "preflight"` and a `✗ preflight failed` hint — expected graceful degradation, not a bug.
- **`weft-sync.fish` is untouched.** It keeps working standalone; retire it later by choice.
- **Conflict resolution stays in the shell.** weft never edits a conflicted tree; the user drops to a terminal. That boundary is deliberate — do not add in-TUI conflict handling.
